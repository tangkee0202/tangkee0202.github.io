街头摄影有一种令人着迷的力量：不可预测的事件、永远不会完全重复的光线，以及匿名感与存在感之间的张力。城市不会摆姿势，不会等待，也不会原谅迟到的快门。

## 极简器材

城市摄影有一个矛盾：相机越大，人们越容易注意到你；越被注意，画面就越不自然。与此同时，携带的器材越多，移动就越困难。

我在 2026 年使用的装备：

| 器材                            | 选择原因                         |
| ------------------------------- | -------------------------------- |
| 紧凑型全画幅相机（Sony A7C II） | 画质优秀，体积低调               |
| 35mm f/2.8 镜头                 | 视角自然，景深容易控制           |
| 一张 256 GB 存储卡              | 不必来回更换，也没有不拍摄的借口 |
| 备用电池                        | 唯一真正值得准备的冗余           |

> 街头摄影不存在“错误的相机”。随身携带的手机，往往比留在家里的单反更容易拍到好照片。

## 技巧：改变一切的拍摄模式

很多年来我一直使用**光圈优先**（Av）。问题在于，街头光线会在几秒内发生变化，快门速度可能产生不想要的拖影，也可能把本该充满生命力的场景冻结得过于僵硬。

现在我使用带曝光补偿的 **P 模式**，只在测光出错时进行调整。这样能把更多注意力留给构图。

弱光场景下，我会使用设置了限制的**自动 ISO**：

- 最高 ISO：25600（黑白照片可以接受，颗粒还能增加性格）
- 最低快门速度：1/160 秒，用于冻结常见的城市运动

## 不被固定规则束缚的构图

三分法、引导线、自然框架等经典规则只是工具，不是教条。真正持续有效的是：

1. **层次：**前景、主体和背景共同形成叙事深度。
2. **侧光：**阴影与高光同样重要。正午直射光下的街道可能很平淡，早晨七点的同一条街却充满戏剧性。
3. **负空间：**城市的视觉噪声非常多，有意识地保留空白反而会成为重要的构图元素。

黑白会移除色彩的“干扰”，迫使构图、纹理和光线承担全部表达。有些彩色照片看起来很有趣，转成黑白后却显得空洞；反过来，普通的彩色场景也可能在灰度中显露隐藏的几何关系。

我在 Lightroom 中的极简处理流程：

- **清晰度：**+20 到 +35，用来增强路面、砖墙和金属等城市纹理
- **阴影：**+30，恢复暗部细节
- **对比度：**保持较低，我更喜欢用色调曲线控制
- **颗粒：**低 ISO 拍摄时主动添加，使整组作品的质感更一致

## 决定性瞬间并非偶然

卡蒂埃-布列松把摄影称为“决定性瞬间”。但他没有说的是：抵达那个瞬间，需要花很多时间观察而不按快门，理解一个地方的规律，并提前预判。

城市有自己的节奏：早上八点的市场、晚高峰的地铁、日落时的广场。了解节奏，意味着在事情发生之前到达，而不是追赶已经过去的画面。
